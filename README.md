A [make.fun](https://make.fun) bounty entry. One satirical sentence about
lawmakers who would regulate AI, crypto or the internet but cannot convert
a file to PDF.

## The roast

> Congress just passed a bill to govern artificial intelligence, drafted by a man who prints his emails, signs them, and scans them back in as a PDF he still cannot open.

## How it works

`main.py` (Python 3.13, standard library only) writes the sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else. Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
